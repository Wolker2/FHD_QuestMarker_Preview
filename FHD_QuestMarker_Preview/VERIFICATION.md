# Проверка 0.3.12-AGL1 в игре

Включить AModGalaxyLite. Требуется FullHD или больше. Убедиться, что карта не смещается, нижняя рамка находится под штатным обрамлением, а метка совпадает с центром звезды.

| Действие | Ожидаемый результат |
|---|---|
| Запросить специальное задание и выбрать «Показать на карте» | Штатный маршрут, анимированная метка в конечной системе, зелёные оценка пути и «Срок: N дн.» |
| Сравнить срок с предложением правительства | Число дней совпадает с текущими условиями задания |
| Изменить сложность предложения и снова показать карту | Срок обновляется по изменённым условиям |
| Нажать сброс на карте | Удаляются линии маршрута и анимированная метка, обе строки очищаются; рамка остаётся |
| Изменить путь вручную | Прежние оценка, срок и метка скрываются |
| Закрыть карту и открыть её через M | Метка и данные предварительного маршрута не возвращаются; фон и кнопка перехода работают |
| Повторно показать предложение | Новый маршрут и метка появляются снова |
| ПКМ по принятому заданию | Сохраняется прежняя анимированная метка цели |
| Сменить разрешение | Исправленная рамка сохраняет положение относительно карты, зелёные надписи читаются |
| Нажать внутри нижней панели при закрытии окон щелчком снаружи | Карта остаётся открытой |

Автоматические проверки не заменяют запуск игры. Для проверки точности времени сравнить игровую дату отправления с датой посадки/прибытия, без боя, ожиданий и смены оборудования. При проблеме вернуть сохранённую рабочую папку из присланного архива с исправленной рамкой.
