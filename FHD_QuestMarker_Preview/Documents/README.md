# FHD Quest Marker — Preview 0.5 / Vanilla Galaxy mechanics

Эта сборка переводит отображение метки и кнопку очистки на механику ванильной галактической карты Space Rangers HD 2.1.2500.

## Метка задания

Ванильная метка текущего положения игрока — `PathCurPos` (`TgaiGI`). В `TfGalaxy2` она обновляется так:

1. координата системы переводится штатной `GalaxyPointToMapPoint`;
2. `Origin` ставится в центр GAI;
3. объект активируется;
4. вызывается `RestartPlayback`.

FHDQuestMark теперь обновляется тем же путём. Ручная формула `CoordX/CoordY` больше не используется.

Используется сам ванильный ресурс:
`Bm.PI.GNPo` -> `common.pkg\DATA\PI\GNPo.gai`.

## Кнопка очистки

Ванильная кнопка с ресурсами `DelN/DelA/DelD` на Galaxy называется `ButDel`.

FHDQuestClearButton при открытии Galaxy:

- находит настоящий ванильный `ButDel`;
- перепривязывается к тому же Parent;
- копирует его LocalPosition, Size, Origin и PositionModeW;
- получает Depth на 1 меньше, поэтому находится поверх ванильного ButDel;
- активна только пока существует FHD-метка.

Поэтому наша кнопка использует тот же автоматический сдвиг интерфейса, который `TfGalaxy2.InitializeLayout` применяет к панели Galaxy при изменении разрешения. Жёстких координат под 1920x1080 больше нет.

Используются ванильные ресурсы:
- `GI,Bm.FormGalaxy2.DelN`
- `GI,Bm.FormGalaxy2.DelA`
- `GI,Bm.FormGalaxy2.DelD`

После очистки FHD-метки наша кнопка скрывается и ванильный `ButDel` снова остаётся доступен.

## Остальная логика

- после предложения правительственного задания появляется пункт `Показать на карте`;
- до принятия используется цель временного QuestOffer;
- после принятия ПКМ по сообщению правительственного задания открывает его цель на Galaxy;
- для планетной цели отмечается её система, для корабля — его текущая система, для системной цели — сама система.

## Установка

Удалить старую папку `Mods\FHD_MODS\FHD_QuestMarker_Preview` целиком и установить новую.

Требуется XenoNativeLoader. Native-часть рассчитана на Rangers.exe 2.1.2500 (13 October 2025), SHA-256 `83300344af802bc51e64389c58f047e5afdf195c133048098be3881fae29ed98`.

## Что проверить

1. Открыть обычную галакарту без метки — вылета быть не должно, ванильный ButDel работает как раньше.
2. Правительство -> `Есть ли для меня специальное задание?` -> `Показать на карте`.
3. Метка должна анимироваться так же, как `PathCurPos`, но стоять на цели задания.
4. При наличии метки кнопка очистки должна точно лежать поверх ванильного ButDel.
5. Проверить 1920x1080 и любое другое разрешение — положение кнопки должно совпадать с ванильным автоматически.
6. Нажать кнопку очистки — FHD-метка исчезает, наша кнопка скрывается, ванильный ButDel снова доступен.
