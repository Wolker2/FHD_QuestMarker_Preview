# FHD Quest Marker — тестовая сборка 0.3

## Что изменено

После выбора в правительстве **«Есть ли для меня специальное задание?»** и появления обычного предложения задания в списке ответов добавляется настоящий пункт **«Показать на карте»**. Это не отдельная графическая кнопка: строка создаётся тем же игровым механизмом `TfGov.AddChoice`, что и «Я берусь за это задание», «Мне надо подумать», «Полегче», «Потруднее» и «Пока».

При нажатии **«Показать на карте»** мод берёт цель прямо из временного `QuestOffer`, то есть ещё **до принятия задания**. Для планеты отмечается её система, для корабля — система, в которой сейчас находится корабль, для системной цели — сама система. После этого открывается галактическая карта.

После принятия задания **ПКМ по сообщению этого задания в информационной панели** также открывает галактическую карту и ставит метку на текущую цель задания.

На галактической карте используется анимированная метка `GNPo.gai` из пользовательского архива **«Метка»**. Кнопка очистки использует `DelN.gi / DelA.gi / DelD.gi` из пользовательского архива **«Сброс»** и скрывает метку.

Пункт **«Показать на карте»** сохраняется и после выбора «Полегче» / «Потруднее», включая крайнее состояние торга.

## Установка

Распаковать папку `FHD_QuestMarker_Preview` в `Mods/FHD_MODS` и включить мод. Требуется XenoNativeLoader. Нативная часть рассчитана на `Rangers.exe` 2.1.2500 (SHA-256 `83300344af802bc51e64389c58f047e5afdf195c133048098be3881fae29ed98`). На другой версии EXE защитные проверки не позволят установить перехваты.

## Что проверить в игре

1. Правительство → «Есть ли для меня специальное задание?» → убедиться, что снизу появился зелёный пункт «Показать на карте».
2. Нажать его → должна открыться галакарта, а анимированная метка должна стоять на **реальной цели предложения**, например для доставки на Уманит — в системе Поллюкс, а не на планете, где находится правительство.
3. Нажать кнопку сброса на галакарте → метка должна исчезнуть.
4. Принять задание → открыть информационную панель → ПКМ по сообщению задания → галакарта должна открыться с меткой цели.
5. Отдельно проверить «Полегче» и «Потруднее»: пункт показа должен остаться.

## Статус проверки

DAT-файлы собраны и декомпилированы обратно без ошибки; DLL собрана как PE32 x86, проверены экспорты и сигнатуры целевого `Rangers.exe`. Адреса `TfGov.AddChoice`, `QuestOffer`, `ObjectiveTarget` и штатного `TGraphButtonGI.ExecuteOnPressCode` сверены с бинарником. Запустить саму Windows-игру в этом окружении нельзя, поэтому финальный щелчок в игре должен быть проверен пользователем.

Исходники находятся в `Source/CFG` и `Source/Native`.
