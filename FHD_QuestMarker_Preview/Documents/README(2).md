# FHD Quest Marker — HYBRID visual fix 2

Основа — рабочая логика открытия карты и определения цели из предыдущей гибридной сборки.

Исправлено:
- выбранная цель теперь передаётся native-части через `FHD_SetMarkerStar`;
- при уже открытой Galaxy вызывается `FHD_RefreshMarker`;
- восстановлена кнопка очистки `FHDQuestClearButton`;
- кнопка автоматически совмещается с ванильной `ButDel`;
- GAI-метка остаётся в отдельном `FHDQuestMarkerControl`, поэтому ванильный `PathCurPos` не перезаписывается;
- открытие через M, пункт правительства и ПКМ по заданию не менялось.

Установка: полностью удалить старую папку `Mods\FHD_MODS\FHD_QuestMarker_Preview` и установить эту версию.

Дополнительная правка visual fix 2: GAI теперь имеет имя `FHDQuestMark` (как ожидает DLL), локальную позицию `0,0`; кнопка очистки также имеет локальную позицию `0,0` внутри своего контейнера.
