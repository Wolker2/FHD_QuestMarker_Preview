# FHD Quest Marker 0.3.8 — без XenoNativeLoader (пробная сборка)

Основа — подтверждённая игроком рабочая версия 0.3.7. Мод загружает `Native/FHDQuestMarker.dll` через штатную систему игры `Data.ScriptLibs`. Инициализация выполняется из `BV.OnStart` и `BV.OnLoad`. XenoNativeLoader и файл `*.XenoPlugin.dll` для этой сборки не нужны.

## Что должно работать

- После «Есть ли для меня специальное задание?» появляется тёмно-синий пункт «Показать на карте». Он показывает место сдачи предлагаемого задания до принятия.
- ПКМ по принятому заданию в правой информационной панели показывает его текущую цель.
- На непрозрачной галакарте остаются штатная метка игрока и анимированная метка `GNPoQ.gai`. Кнопка сброса встроена в штатную нижнюю кнопку; переход к выбранной системе работает в режиме 2.

Важное различие: **это не полностью скриптовый мод**. Для получения ещё не принятого `QuestOffer`, добавления пункта именно после запроса задания и перехвата ПКМ по выбранному сообщению DLL по-прежнему изменяет обработчики в памяти `Rangers.exe`. Изменился только штатный способ её загрузки. Без DLL и изменения EXE сохранить эти три действия на версии игры 2.1.2500 не позволяет доступный интерфейс модов.

## Установка и проверка

Закрыть игру, заменить только папку `Mods/FHD_MODS/FHD_QuestMarker_Preview` содержимым папки архива, включить мод. На время проверки отключить Xeno-копию этого мода и не загружать её одновременно. Остальные моды и фон галакарты не затрагиваются.

Рассчитано на `Rangers.exe` 2.1.2500, SHA-256 `83300344af802bc51e64389c58f047e5afdf195c133048098be3881fae29ed98`. На ином EXE DLL не устанавливает перехваты. Загрузка через `ScriptLibs` проверена по исходному коду игры; сборка DAT, x86 DLL, состав экспорта и слияние с ванильной конфигурацией и FHD_Trade проверены. Запуск Windows-игры в этой среде недоступен: работу после загрузки сохранения и начала новой партии нужно проверить в игре. Версия 0.3.7 сохранена как точка отката.

Исходники находятся в `SOURCE/CFG` и `SOURCE/Native`. DLL загружается при начале новой игры или загрузке сохранения. После установки перехватов она остаётся в памяти до закрытия игры, поскольку штатный кеш ScriptLibs освобождается при сбросе партии.
